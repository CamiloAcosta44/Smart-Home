# Smart-Home
Diseñar un sistema IoT para automatizar luces y persianas mediante sensores de movimiento y luz. La solución busca reducir el consumo energético, aprovechar la iluminación natural, disminuir la intervención manual y mejorar la comodidad en el hogar.
